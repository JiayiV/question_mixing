# Business agent skills

This directory preserves a curated set of public `SKILL.md` files for agents
working on business, go-to-market, communication, planning, and analytics
tasks. Each skill remains in its own directory so it can be copied directly
into a compatible agent's skills location.

## Provenance

The preserved skills were collected from the public
[github/awesome-copilot](https://github.com/github/awesome-copilot) repository,
from its `main` branch on 2026-08-25. The upstream repository and individual
skills include their applicable license and author information in their
metadata. Files are retained without content changes; consult each
`SKILL.md` for its specific attribution and license details.
