# Agent skills catalog

This directory contains a broad catalog of reusable public `SKILL.md`
instructions. Each skill remains in its own directory so it can be copied
directly into a compatible agent's skills location.

## Catalog

The catalog currently contains 648 skill assets:

- 427 upstream skills covering development, data, cloud, product, business,
  communication, and other workflows.
- 221 upstream agent instruction assets, exposed with an `agent-` prefix so
  they can be discovered and installed through the same skill interface.

Use the directory names as stable skill identifiers. Every entry contains a
`SKILL.md` file with its own frontmatter, attribution, and usage instructions.

## Provenance

The catalog was collected from the public
[github/awesome-copilot](https://github.com/github/awesome-copilot) repository,
from its `main` branch on 2026-08-25. Upstream skills and agent assets include
their applicable license and author information in their metadata. Files are
retained without content changes; consult each `SKILL.md` for its specific
attribution and license details.
